# SEED-DATA — بيانات تجريبية للتطوير و`staging`

> الحالة: مواصفات. السكربت `pnpm seed` يُنشأ في المرحلة 2 ويتوسع مع كل مرحلة. **لم يُنفَّذ ولم يُختبر.**

## القواعد
1. **وهمية بالكامل:** لا أسماء/هواتف/عناوين/أسعار شراء حقيقية. أرقام الهواتف من نطاق غير مستخدم أو بصيغة مميزة (مثل `+2189000xxxxx` مخصَّصة للتجريب)، وأسماء مولَّدة.
2. **حتمية:** نفس البذرة تنتج نفس البيانات (للاختبار والتكرار).
3. **متكررة التشغيل (idempotent):** إعادة التشغيل لا تكرر السجلات (مفاتيح طبيعية: SKU، هاتف، اسم مستخدم).
4. **ترفض الإنتاج:** تقرأ `APP_ENV` وبصمة قاعدة الإنتاج وتتوقف (ADR-0031).
5. **تمر عبر الخدمات العامة للوحدات** (لا إدخال مباشر في الجداول)، فتجرّب القواعد نفسها: الحجز، القيود، الصلاحيات.
6. **مستويات:** `pnpm seed --size small|medium|large` (large لاختبار الأداء والداشبورد).

## حالات صعبة مزروعة عمدًا (تشمل v5: تقريب خصم على 3 خانات، عربون ثم إلغاء، جرد يخفض دون المحجوز)
SKU على الحد، مبالغ 3 خانات عشرية، متغير مخزونه 1 (لاختبار التزامن)، طلب بسطرين أحدهما غير متوفر، قيد غير متوازن **يُحاول** النظام رفضه (في اختبارات لا في البذرة).
