# ADR-0022: التقارير والداشبورد الاحترافية
الحالة: مقترح

## قرار المالك
تقارير مبيعات مفصلة وداشبورد احترافية جدًا.

## قرارات مقترحة
- **أبعاد التحليل:** الفترة، الفرع، المخزن، القناة (متجر/POS)، المصدر/الحملة، المندوب/شركة الشحن، الصنف/المتغير، التصنيف، طريقة الدفع. مع مقارنة بفترة سابقة.
- **مؤشرات الداشبورد:** المبيعات، الأرباح الإجمالية والصافية (بعد تكلفة البضاعة والتوصيل والإعلان)، عدد الطلبات ومتوسط السلة، نسبة التحويل والتسليم والإلغاء والمرتجع، المنتجات الأكثر/الأقل مبيعًا والراكدة، المخزون المنخفض، عُهد المناديب المعلّقة، رصيد الخزينة والبنك، ROAS لكل حملة، أداء المناديب، خريطة المناديب (من ADR-0018).
- **الأداء على قاعدة مجانية:** جداول ملخصة تُحدَّث عند الترحيل أو بمهمة مجدولة + تخزين مؤقت، فلا استعلامات ثقيلة مباشرة.
- **الرسوم:** مكتبة مجانية (مثل Recharts)، تجاوب كامل للجوال، RTL.
- **الصلاحيات:** كل دور يرى ما يخصه فقط (فرع الموظف، مبالغ المحاسبة…).
- **التصدير:** CSV/Excel/PDF.
- **قاعدة ذهبية:** كل رقم في الداشبورد يطابق تقريره المحاسبي (اختبار مطابقة).

## ما لم يُختبر
كل شيء. اختبارات المرحلتين 12 و18: مطابقة مجاميع الداشبورد مع ميزان المراجعة، ومع بيانات اختبار بحجم كبير (زمن استجابة يُحدد رقمه معك).
