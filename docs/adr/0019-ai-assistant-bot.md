# ADR-0019: بوت الردود الذكي
الحالة: مقترح

## قرار المالك
يتمنى بوتًا ذكيًا «إن أمكن مجانًا».

## ما وجدته (مصادر منشورة 2026، غير مجرّب)
- **Cloudflare Workers AI:** حصة مجانية مشتركة نحو 10,000 «Neuron» يوميًا للحسابات المجانية، بنماذج مفتوحة؛ ويُذكر أنها لا تُدرِّب على بياناتك.
- **Google Gemini API (مجاني):** سخي لكن بحسب مصدر منشور **محتوى الطبقة المجانية يُستخدم لتحسين منتجات جوجل**، فلا نرسل له بيانات زبائن.
- **Cohere (تجريبي):** للاستخدام غير التجاري فقط ⇒ مستبعد.
- **جودة العربية والحد اليومي** لم أتحقق منهما؛ يحسمهما اختبار.
- **المجاني مقيَّد دائمًا** (حد يومي)، فلا ضمان لمتجر ناجح.

## القرارات المقترحة
**مستويات:**
- **م0 — بوت قواعد (مجاني، حتمي):** «أين طلبي؟» (برقم الطلب + الهاتف)، أوقات العمل، التوفر والمقاسات، سياسة التوصيل/الإرجاع. بلا ذكاء اصطناعي، دقيق وبلا تكلفة.
- **م1 — نموذج لغوي مجاني** لفهم أسئلة حرّة بالعربية فوق م0، ويُنفّذ فقط أدوات **قراءة** محددة.
**القنوات:** نافذة محادثة في **موقع المتجر أولًا**. واتساب يحتاج WhatsApp API (غير متوفر الآن) ⇒ مؤجل مع المرحلة 13. رسائل فيسبوك/إنستغرام تحتاج مراجعة تطبيق من Meta ⇒ لاحقًا (لم أتحقق من الشروط).

**حواجز أمان إلزامية:**
1. البوت **لا يغيّر طلبًا ولا سعرًا ولا مخزونًا ولا يلغي** — يقرأ ويجيب فقط؛ أي تعديل يحوَّل لموظف.
2. لا يرى بيانات زبون آخر؛ التحقق برقم الطلب + الهاتف.
3. حماية من حقن التعليمات (prompt injection): نص الزبون بيانات لا أوامر.
4. تحويل لموظف عند عدم الثقة/الإحراج/الغضب.
5. حدّ للطلبات لكل مستخدم، وسجل المحادثات (دون بيانات حساسة).
6. لا يعد بشيء غير موجود في قاعدة المعرفة («لا أعرف» مقبول).

## ما لم يُختبر
كل شيء. شرط نجاح المرحلة 20: مجموعة اختبارات أسئلة عربية (أسئلة عادية، لهجة، محاولات حقن، سؤال عن زبون آخر) تنجح، وتجربة يدوية منك.
