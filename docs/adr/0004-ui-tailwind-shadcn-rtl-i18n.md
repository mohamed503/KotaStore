# ADR-0004: الواجهة — Tailwind CSS + shadcn/ui + RTL أولًا + i18n
الحالة: مقترح

## السياق
واجهة عصرية متجاوبة، عربية أولًا مع إنجليزي بضغطة زر، ومكونات قابلة لإعادة الاستخدام عبر المتجر والإدارة وشاشة المندوب.

## الخيارات
1. **Tailwind + shadcn/ui (Radix)** — مكونات مملوكة في مشروعنا (ننسخها ونعدّلها)، وصولية جيدة، تخصيص كامل. (اختيارك)
2. مكتبة جاهزة (MUI/Ant) — سريعة لكن ثقيلة وصعبة التخصيص وRTL يحتاج عملًا.
3. CSS مخصص — تحكم كامل وبطء كبير.

## القرار المقترح
- Tailwind + shadcn/ui مع «رموز تصميم» (design tokens) موحّدة: ألوان، مسافات، خطوط.
- **RTL أولًا:** خصائص منطقية فقط (`ms-`, `me-`, `ps-`, `pe-`, `start`, `end`) ويُمنع `left/right` إلا لسبب موثّق.
- i18n بمكتبة `next-intl` (أو ما يعادلها): ملفات ترجمة عربي/إنجليزي، تبديل اللغة يقلب الاتجاه.
- خط عربي واضح يُحدَّد في المرحلة 1 مع مراعاة الأداء.
- أرقام: عرض موحّد (أرقام غربية أم هندية) كإعداد يُحسم معك.

## السبب
يعطي هوية بصرية خاصة وسرعة تطوير وإعادة استخدام، وRTL من الأساس أرخص من إصلاحه لاحقًا.

## العواقب والمخاطر
- بعض مكونات Radix تحتاج تعديلات RTL: تُختبر لكل مكوّن.
- ترجمات ناقصة: اختبار يفشل عند مفتاح ترجمة مفقود.

## ما لم يُختبر
سلوك كل مكوّن shadcn في RTL، وأداء الخط العربي على الجوالات الضعيفة.
