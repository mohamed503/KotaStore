# ADR-0030: صيغة الأخطاء الموحدة
الحالة: مقترح

## السياق
واجهة ثنائية اللغة وعمليات مالية: رسائل الخطأ يجب أن تكون ثابتة ومفهومة وآمنة ولا تسرّب تفاصيل داخلية. (v3)

## القرارات المقترحة
1. **غلاف موحَّد** لكل خطأ متوقع يصل للواجهة أو لواجهة برمجية:
   ```
   { "error": { "code": "ORDER_NOT_CONFIRMABLE", "messageKey": "errors.order.notConfirmable",
                "params": {"orderNumber": "KS-2026-000123"}, "requestId": "…", "fields": {"phone": "INVALID_PHONE"} } }
   ```
   - `code`: ثابت بالإنجليزية `UPPER_SNAKE` (لا يتغير بين النسخ).
   - `messageKey`: مفتاح ترجمة (ar/en)؛ النص يُركَّب في الواجهة لا في الخادم.
   - `params`: متغيرات آمنة للعرض فقط.
   - `fields`: أخطاء حقول النموذج (من Zod) بأكواد لا نصوص.
   - `requestId`: يظهر للمستخدم ليذكره للدعم ويربط بالسجلات.
2. **الفئات:** `VALIDATION` · `AUTH` · `FORBIDDEN` · `NOT_FOUND` · `CONFLICT` (مثل مخزون غير كافٍ، حالة طلب لا تسمح) · `RATE_LIMITED` · `UPSTREAM` (واتساب، تخزين) · `INTERNAL`. لكل فئة رمز HTTP مناسب (400/401/403/404/409/429/502/500).
3. **أخطاء متوقعة = قيمة نتيجة** (`Result`) من الخدمات و`Server Actions`، لا استثناءات؛ الاستثناءات للأعطال غير المتوقعة فقط.
4. **ربط قيود القاعدة بأخطاء المجال:** انتهاك `UNIQUE(sku)` ⇒ `SKU_ALREADY_EXISTS`؛ فشل `CHECK` للتوازن ⇒ `JOURNAL_UNBALANCED`؛ لا يُرمى نص SQL للواجهة أبدًا.
5. **الأمان:** لا Stack ولا SQL ولا أسماء جداول ولا بيانات شخصية في الاستجابة. رسائل الدخول لا تفرّق بين «المستخدم غير موجود» و«كلمة مرور خاطئة».
6. **الأخطاء غير المتوقعة:** استجابة `INTERNAL` عامة + `requestId`، والتفاصيل في السجلات المقنَّعة وتتبع الأخطاء (ADR-0027).
7. **ترجمات:** كل `code` له ترجمة عربية وإنجليزية وإلا يفشل الاختبار (امتداد لاختبار المفاتيح الناقصة).
8. **سجل أكواد الأخطاء** في ملف واحد مُتحقَّق منه بنوع TypeScript (union)، فلا يُنشأ كود دون تسجيله.

## الخيارات المرفوضة
نص الخطأ من الخادم بلغة ثابتة (يكسر ثنائية اللغة)، أو استثناءات لكل فشل متوقع (تُخفي حالات الإدخال العادية).

## ما لم يُختبر
كل شيء. اختبارات: كل رمز له ar وen؛ لا Stack في الاستجابة؛ تحويل انتهاكات القاعدة لرموز مجال؛ `requestId` يظهر في السجل المقابل.
