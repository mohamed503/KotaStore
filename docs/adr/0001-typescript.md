# ADR-0001: لغة البرمجة — TypeScript (وضع strict)
الحالة: مقترح

## السياق
نظام مالي ومخزني: أخطاء الأنواع (مبلغ مقابل كمية، معرّف طلب مقابل معرّف متغير) مكلفة.

## الخيارات
1. **TypeScript strict** — أنواع ثابتة من الواجهة إلى قاعدة البيانات؛ نفس اللغة للواجهة والخادم؛ ما اخترته أنت.
2. JavaScript — أسرع للبداية، لكن أخطاء تظهر وقت التشغيل.
3. لغة خلفية منفصلة (Python/Go/PHP) — تفصل الفريق وتضاعف العمل لمشروع بهذا الحجم.

## القرار المقترح
TypeScript مع `strict: true`، ومنع `any` الضمني، وأنواع «معلَّمة» (branded) للمبالغ والمعرّفات.

## السبب
يلتقط أخطاء كثيرة قبل التشغيل، ويدعم إعادة الاستخدام الآمنة للمكونات والخدمات.

## العواقب والمخاطر
منحنى تعلم أعلى قليلًا؛ وقت بناء أطول. مقبول.

## ما لم يُختبر
إعدادات التدقيق الصارمة مع الإطار المختار — تُختبر في المرحلة 1.
