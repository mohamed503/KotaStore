# ADR-0010: الإعلانات الممولة — المصاريف والإسناد
الحالة: مقترح

## السياق
المتجر يعلن على فيسبوك وإنستغرام، ويجب أن تدخل مصاريف الإعلان في الدورة المحاسبية ويُعرف ربح كل حملة.

## القرارات المقترحة
1. **المرحلة الأولى: إدخال يدوي** لمصروف الإعلان: (منصة، حملة، فترة، مبلغ، عملة، سعر صرف) → قيد «مصروف إعلان/تسويق» مقابل حساب (بنك/نقد/بطاقة/ذمة المنصة).
2. **الإسناد**: التقاط معاملات UTM ومعرّف النقر عند أول زيارة، وحفظها مع الطلب. طلبات بلا إسناد = «مباشر/غير معروف».
3. **التقارير**: تكلفة الاكتساب (CAC) وعائد الإنفاق (ROAS) وصافي ربح الحملة = هامش الطلبات المُسلَّمة − مصروف الحملة.
4. **لاحقًا**: استيراد آلي من Meta Marketing API وإرسال أحداث عبر Conversions API (يتطلب موافقة وإعدادًا من حسابك).
5. بكسل Meta يُحمَّل بموافقة الزائر حيث يلزم، وبدون تسريب بيانات شخصية خام.

## العواقب والمخاطر
- الإسناد غير مثالي (حاجبات الإعلانات، الطلب عبر واتساب مباشرة): نعرضه كتقدير ونوضح ذلك.
- الدفع للمنصة بعملة أجنبية: يعتمد على ADR-0005 (فروق صرف).

## ما لم يُختبر
كل شيء، ولا تواصل فعلي مع Meta حتى الآن.
